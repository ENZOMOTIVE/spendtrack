## Getting Started

### Prerequisites

- Git
- Node.js 18+

### Setup and Run

```bash
git clone https://github.com/ENZOMOTIVE/spendtrack.git
cd spendtrack
```

```bash
cd MAO-backend
npm install
```

```bash
cd frontend
npm install
npm run dev
```
